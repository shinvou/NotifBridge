# Changelog

## 1.0.0

First source release of the ESP32-backed iPhone-to-Mac notification bridge.

- Native Mac notifications, supported reply/actions and explicit iPhone clearing.
- SwiftUI menu-bar controls and chronological, searchable notification history.
- ESP32 BLE relay with chunk acknowledgments and reverse commands.
- Mac acceptance receipts, bounded retries and duplicate suppression.
- Durable two-phase key exchange and recovery after extension interruption.
- Background Bluetooth restoration and notification ordering regressions.
- App icons, rich content previews, attachment export and sound controls.

This release requires developer provisioning and physical hardware. It includes
no notarized binary, delivery SLA, or independently audited security guarantee.
